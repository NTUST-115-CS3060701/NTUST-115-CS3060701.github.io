    課程概覽

    CS3060701 系統開發實務是一門介紹現代系統開發基礎概念的課程。本文件目前涵蓋的內容主要圍繞三個主題：API、認證與授權，以及授權載體（Token）。

    第一部分介紹 API（Application Programming Interface）。內容從 API 的基本概念開始，說明 API 在不同層級的存在形式，例如語言級別的 API、作業系統 API，以及 Web 系統中常見的 RESTful API。這一部分的目的是讓讀者理解 API 在軟體系統中的角色，以及不同種類 API 的差異與用途。

    第二部分討論 認證與授權（Authentication & Authorization）。在這一段中，會介紹系統如何確認一個主體的身份，以及如何決定該主體是否有權存取某個資源。相關主題包含信任邊界、可驗證的主體、存取控制的基本概念，以及常見的存取控制模型，例如基於角色的存取控制與基於屬性的存取控制。同時也會說明 API 系統中常見的授權相關概念，例如 scope、claim 與 audience。

    第三部分介紹 授權載體（Token）。內容包括什麼是 Token、JSON Web Token 的基本結構，以及系統中常見的權杖類型，例如存取權杖與更新權杖。除了權杖本身的形式之外，也會說明權杖在系統中的生命週期管理，例如權杖管理與權杖撤銷。

    在後續的內容中，也會補充資料庫規劃、分散式系統的概念。

    整體而言，本課程並不只教授單一技術，而是建立學生對 現代分散式系統與 Web API 架構的理解。完成課程後，學生應能理解 API 的設計原則、身份驗證與授權的基本機制，並能在實際系統開發中應用這些概念。
